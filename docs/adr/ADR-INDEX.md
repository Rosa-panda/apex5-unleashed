# ADR · 架构决策记录索引（存量补录 2026-09-18）

> 格式：背景/选项/决定/后果。新决策追加编号，勿改旧条。

## ADR-001 游戏场景音频方案砍掉
背景：v1 全局跟随傻震，v2 事件驱动仍有 BGM 误触发。用户拍板"放弃！任何游戏都会有背景音乐"。
决定：游戏不走音频分析（信息论之墙：混音后事件意图不可恢复）。音频中间件仅历史保留，不入产品。
后果：产品=桥接(游戏)+预设(长尾)。

## ADR-002 K6/cmd87 实时流判死（八5）
背景：cmd 87 在八5 干净基线下 ACK-but-ignore；官方 SDK 逆向确认八5 适配 0 使用 K6 家族。
决定：不再扫 83-87 组合，不追八6 X-Haptics。
后果：八5 实时数据通道只有 cmd 18 流式 + cmd 82 路由。

## ADR-003 产品定位：桥接+实验室，不做官方平替
背景：官方 93 款适配=静态参数包+震动转发（逆向实锤），无事件级控制。
决定：只做官方架构做不了的（虚拟 DS 桥接、协议全开放、社区预设），键位/宏/陀螺转摇杆不重做。
后果：核心卖点依赖桥接质量 → 实测 B3/B4 为前置验证。

## ADR-004 UI：React+Vite+TS+Tailwind+深色科技风
背景：三案对比（React+shadcn / Vue+Naive / Svelte）。
决定：React 生态最大；shadcn 以 Tailwind token 手工实现（免 CLI 依赖）；bg #0a0a0f/强调 #22d3ee。
后果：壳 pywebview(WebView2)，前后端分离，未来可换壳。

## ADR-005 架构：Python 单服务 + webview 壳
背景：协议/验证资产全在 Python；C# 重写成本 2-3 天但音频已砍无 numpy 负担。
决定：v0.1 Python（FastAPI 127.0.0.1:18765 + WS），主线程 webview、uvicorn daemon 线程。C# 为长期备选。
后果：PyInstaller 体积 ~100MB 可接受；换壳不动核心。

## ADR-006 代理权检测=功能非风险
背景：用户指出官方也显示"被 Steam 接管"，且不止 Steam。
决定：三层检测（总线回显铁证/进程归因/一致性校验-v0.1不做），状态签不打扰。
后果：R11 降级；事件日志成为产品功能。

## ADR-007 许可证 GPLv3
背景：MIT 防不住闭源白嫖；CC BY-NC 非 OSI。
决定：GPLv3。商用允许但必须开源回馈。
后果：建仓时落实 LICENSE 与头部声明。

## ADR-008 游戏检测：SetWinEventHook（v0.2）
背景：官方 tasklist 轮询 → 云端意见建议事件驱动。
决定：EVENT_SYSTEM_FOREGROUND 钩子（需独立消息泵线程），失败退 1Hz GetForegroundWindow 轮询。
后果：切换零延迟；实现糙点已知。

## ADR-009 DSX UDP ingress（v0.2）防洪坝位置
背景：接 7878 兼容 DSX mod 生态。云端意见建议收包端丢旧留新。
修正决定：收包端只排空（内核自然丢包），按指令类型分流——状态类 latest-wins 单槽、瞬态类必达小队列；限频坝建在 HID 写出层（真瓶颈是 32B 中断端点）。
后果：不丢瞬态事件（脉冲类）；端口冲突探测入 R13。

## ADR-010 启动卫生检查
背景：atexit/SIGINT 拦不住 TerminateProcess；发生过强杀残留效果事故。
决定：每次设备连上先无条件 panic（反正账本为空，清的是历史残留）。
后果：强杀场景自愈；SIGINT 仍注册（免费）。

## ADR-011 Mock 设备层
背景：R4 硬件在环单点。
决定：Transport 抽象 HidPad/MockPad（5ms 合法 ACK），无手柄自动 Mock；未来 trace 回放挂同层。
后果：全自动开发/CI 成为可能。

## ADR-012 HID 单读写线程 + 10ms 超时读
背景：审阅指出 hid_read 阻塞饿死写。
决定：线程H主循环 读(10ms超时)→写队列→发；真防线是"单处 open 设备"（hidapi 写读本可跨线程）。
后果：流式命令与队列命令共用写锁防帧交错。
