# ADR-024：ASB 条目 vib 种子参数全自动生成（官方调参学题材映射）

日期：2026-09-20 · 状态：已接受

## 背景

ADR-022 引入的 181 条 ASB「DS 原生」条目当前是死数据：零 vib、零 preset，
行为上与库外游戏无差别（仅 exe 匹配 + 展示）。用户决策：
- 本机**只装本工具**，不装任何桥/虚拟设备（ASB 已卸，ADR-020 revB 终局）；
- 拒绝逐款手调（没时间也没下载全部游戏）；
- 要求「全部转成我们工具的格式」，**全自动**。

机理事实（说死）：DS 原生游戏的"事件级配置"是运行时发给 DualSense 的输出报告流，
无 DualSense 设备在场则**根本不会产生**——不存在可"转换"的静态配置。无桥前提下
事件级 = 0 可能。可转换的只有**体验**：逐游戏 vib 参数包（与官方 34 条同构），
走既有链路：进游戏 → autoswitch 匹配 → cmd 0x52 固件路由 → 震动变扳机反馈。

## 场外经验（2026-09-20 联网调研）

- **DS4Windows fork（hbashton）Trigger Lab 的「Triggers from Rumble」**：社区已验证
  "把震动信号实时转成扳机效果"这一方向成立（VIIPER 组件与 ASB 同源生态）；
- Steam `appdetails?filters=genres` 公开 API 提供全量游戏题材标签（免费、限流宽松）；
- 最关键：**飞智官方 34 条逐游戏 vib 调参本身就是「题材→参数」的标注数据**
  （竞速=stroke 高 freq 高、FPS=stroke 0 短促、大作双人向 press 高），无需拍脑袋造参数表。

## 决策

1. **生成方法：官方条目题材集 k-NN 加权平均**。
   - 特征：Steam genres 集合（英文 id+名，缓存到 %APPDATA%\Apex5Unleashed\genre_cache.json，
     直连失败走本机代理 127.0.0.1:10808，全部失败则中止不写盘）；
   - 对每条 ASB 条目：与 34 条官方 vib 条目算题材集交叠 |G∩O|，交叠>0 者按交叠大小
     加权平均六参数（filter/scale/stroke/press/strength/freq），clamp 到官方观测值域；
   - 无交叠回落 FPS 主簇均值（游戏库绝大多数为动作/射击题材）。
2. **产物**：回写内置 `asb-*.json`，加 `vib` + `"vib_source": "asb-seed"` + `"genres"`。
   幂等可重跑；官方条目与用户档案一律不碰；`tools/update_asb_list.py` 未来重导时
   需保留已生成字段（下游注意）。
3. **链路零改动**：vib 进档案后 autoswitch/match/apply_game 自动生效，无新机制。
   「无专属适配参数」提示仅对真正无参数游戏保留。
4. **不做**：per-game 手调 UI（后续需求再说）；事件级（无桥不可能，见背景）。

## 后果

- 库内 267 款游戏全部有逐游戏反馈参数；ASB 条目从"信息标签"升级为真适配档案；
- 生成参数是启发式种子（题材级合理默认，非逐游戏精调）——用户实际游玩觉得不对时
  可手调单款（未来功能）；参数质量上限 = 官方 34 条的题材覆盖度；
- DS 原生角标语义不变（游戏本身支持 DS 事件级的客观事实），但档案现在"有货可套"；
- Steam API 依赖仅存在于生成期（离线缓存可重放），运行期零外部依赖。
