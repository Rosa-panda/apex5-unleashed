# ADR-015 统一游戏配置格式 apex5-game-config/1 + 开发者工具链

日期：2026-09-18（设计定稿，v0.2 实现）

## 背景
用户提出：第三方配置（DSX 档案）与官方配置（93 适配包）能否统一格式，并做成
"让别人自己开发游戏适配配置"的工具。现状三方（官方 protobuf 包 / DSX JSON / 我们的预设+档案）
本质同为「游戏→匹配键→扳机动作」，方言可归一。

## 决定
1. **单一开放格式 `apex5-game-config/1`**，三段式：
   - meta：game{name, exe[]}（匹配键）
   - startup：进场静态预设（官方包/预设/DSX 档案全部归一化到这段）
   - events[]：事件规则（`on` 匹配桥接 DS 事件或 UDP ingress 包 → `do` 动作；参数可引用事件字段 `$xxx`）
2. **工具链**：
   - JSON Schema + `validate` 命令
   - Mock 试驾：开发者无手柄验证命令流（事件日志即验证 UI）
   - 导入器：官方包 / DSX 档案 → v1（一个转换层吃两家）
   - 社区仓库：纯 JSON 文件 PR 即贡献，应用内"从仓库更新"
3. 现有 preset / gameprofile JSON 为 v1 格式的 startup 段前身，v0.2 平滑合并（读旧写新）。

## 后果
- 项目生态位：八5 社区适配标准的定义者；官方封闭 vs 我们开放。
- 事件段依赖 v0.2 两个 ingress（DS 桥接、UDP 7878）——格式先行，ingress 到位即激活。
- R5（协议漂移）多一层保险：格式与协议解耦，协议变化只动翻译层。
